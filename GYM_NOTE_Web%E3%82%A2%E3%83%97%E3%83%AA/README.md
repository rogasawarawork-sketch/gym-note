# GYM NOTE — スマホ筋トレ管理アプリ

iPhone / Android のブラウザで使える、依存ライブラリ不要のWebアプリです。ダークテーマ、筋トレ記録、重量・推定1RMの種目別成長、週・月グラフ、体重・体脂肪、カレンダー、目標、JSONバックアップ・読込、筋トレCSV出力に対応。

## 使い方

1. `index.html` をブラウザで開くと基本機能を利用できます。
2. ホーム画面追加やオフライン機能を利用するには、このフォルダの**全ファイル**をHTTPS対応の静的ホスティング（例: GitHub Pages / Netlify / Cloudflare Pages）に配置し、公開URLをスマホで開いてください。単なる `file://` ではPWA機能は使えません。
3. iPhone: Safari → 共有 → ホーム画面に追加。Android: Chrome → メニュー → アプリをインストール/ホーム画面に追加。
4. 保存先は各ブラウザの `localStorage` です。**サーバー同期はしません**。設定 → JSON保存で定期的にバックアップし、別の端末ではJSON読込を使ってください。

## 筋トレ管理シートとの関係

以前のExcel/Googleスプレッドシートの項目・サンプル目標を反映したアプリです。既存Excelデータの自動同期・直接インポートには未対応。アプリ内のCSV出力をスプレッドシートで開くことはできます。

## セキュリティと限界

データはクラウド送信しません。ブラウザの閲覧データを消去すると消える可能性があります。JSONのインポートは上書きです。App Store / Google Playでの配信は行っていません。
